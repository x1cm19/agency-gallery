# معرض العملاء — الوكالة

موقع بسيط على GitHub Pages، كل عميل له صفحة معرض صور خاصة برابط ثابت خاص فيه.

## هيكل المشروع

```
agency-gallery/
├── index.html              ← صفحة عامة (لا تحتوي صور)
├── robots.txt               ← يمنع فهرسة الموقع في جوجل
├── .nojekyll
└── g/
    ├── KDH/
    │   ├── index.html       ← معرض KDH
    │   └── photos/           ← صور KDH (ترفعها هنا مباشرة)
    │       ├── KDH (1).jpg
    │       └── KDH (2).jpg
    └── spence/
        ├── index.html       ← معرض spence
        └── photos/
            ├── spence (1).jpg
            └── spence (2).jpg
```

الروابط اللي ترسلها:
```
https://YOUR-USERNAME.github.io/agency-gallery/g/KDH/
https://YOUR-USERNAME.github.io/agency-gallery/g/spence/
```

## تسمية الصور

رتّب أسماء الصور بجهازك بنمط Windows التلقائي (تحديد الكل → Rename → اكتب الاسم):

- صور KDH: `KDH (1).jpg`, `KDH (2).jpg`, `KDH (3).jpg` ...
- صور spence: `spence (1).jpg`, `spence (2).jpg`, `spence (3).jpg` ...

قائمة `photos` داخل كل `index.html` معبّأة مسبقًا على نفس هذا النمط — لو رفعت نفس عدد
الصور بنفس الأسماء بالضبط، ما تحتاج تعدّل شي غير عدد العناصر لو زاد أو نقص.

## كيف ترفع/تحدّث الصور

1. ادخل داخل مجلد `g/KDH/photos/` (أو `g/spence/photos/`) من داخل GitHub
2. **Add file → Upload files**
3. حدد **الصور نفسها** من جهازك واسحبها (لا تسحب مجلد كامل — لازم تدخل المجلد وتحدد
   الملفات اللي بداخله)
4. اضغط **Commit changes**
5. افتح `index.html` وتأكد إن قائمة `photos` تطابق عدد وأسماء الصور اللي رفعتها،
   وحط `isNew:true` على الجديدة منها

## إضافة عميل ثالث لاحقًا

1. سوّي نسخة من مجلد `g/KDH/` كامل (بما فيه `photos/`) وسمّه باسم العميل الجديد
2. غيّر العنوان `<title>` واسم العميل في `.client-name` داخل `index.html`
3. حدّث قائمة `photos` بنفس نمط التسمية

## قبل ما ترفع أي صورة

اضغطها (Compress) أول — صور الكاميرا/الآيفون تكون كبيرة (٥-١٥ ميجا) وتبطّئ فتح المعرض
على الجوال. أداة Squoosh (squoosh.app) مجانية وسهلة، والحجم المناسب للويب
حوالي ٢٠٠-٦٠٠ كيلوبايت للصورة الواحدة.

## نقاط مهمة

- **الخصوصية:** الروابط هنا بأسماء مباشرة (KDH, spence) بدون رمز عشوائي —
  سهلة التذكر لكنها أسهل تخمينًا من رابط برمز عشوائي. مناسبة لو المحتوى غير حساس.
- **الجوال:** الصفحة مصممة لتشتغل بسلاسة على الجوال — شبكة متجاوبة، وسحب بالإصبع
  للتنقل بين الصور داخل العرض الكبير.
